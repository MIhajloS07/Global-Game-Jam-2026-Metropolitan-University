## Overview

**UnderCover** is a local multiplayer fighting game created in 48 hours during **Global Game Jam 2026**, whose theme was **"Mask"**. We interpreted the theme both literally and symbolically: a mask is protection and anonymity, but also a weakness waiting to be exposed.

## Story

When a mysterious group of cyber criminals begins attacking the global web, one man decides to assemble a team to find out who these masked hackers really are, and to stop them.

The game lets you fight on two fronts:

- **Against the bad side**, to put an end to cybercrime.
- **Against the good side**, to uncover more about the villains.

The idea stems from a desire to stop hackers and illegal activity on the internet. Its central message is simple: hackers are strong only while they hide behind their screens, just as the characters in the game are strong only while their masks are on.

> **So let their masks fall.**

### Design pillars

| Pillar | What it means |
|:---|:---|
| **Identity as power** | A mask is a source of strength. Take it away and the character is exposed. |
| **Two sides of the fight** | Fighting is not only about beating villains, but also about learning who they are. |
| **Pick up and play** | Local multiplayer on a single machine, with no setup and no installation. |

## Getting Started

### Play the game

1. Open the **[UnderCover page on itch.io](https://mihajlo-stoiljkovic.itch.io/undercover)**.
2. Download **`UnderCover.exe`** (about 38 MB).
3. Run the installation file (Standard Wizard installation)
4. Run the game and enjoy with friends 

> [!NOTE]
> Windows may show a SmartScreen warning because the game is not digitally signed. This is normal for independent games and the game is completely safe. Select **More info**, then **Run anyway**.

## Build from Source

### Prerequisites

- [GameMaker](https://gamemaker.io/) (a recent version that can open the project)
- Windows

### Steps

```bash
# Clone the repository
git clone https://github.com/MIhajloS07/Global-Game-Jam-2026-Metropolitan-University.git
cd Global-Game-Jam-2026-Metropolitan-University
```

1. Open the project's `.yyp` file in GameMaker.
2. Press **F5** to run the game.
3. To export a standalone build, use **Build > Create Executable**.
